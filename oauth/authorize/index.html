/oauth/authorize

Diese statische Seite leitet zur GitHub-OAuth-Autorisierungs-URL weiter. Sie führt keine Token-Exchanges durch — das muss serverseitig erfolgen.

Schnellstart: Du kannst auch `?client_id=...&redirect_uri=...` an diese URL anhängen, dann leitet die Seite automatisch weiter.

Anmerkungen

  • GitHub Pages ist statisch und sicher — gehe niemals Geheimnisse (Client Secret) in statischen Seiten ein.
  • Der vollständige Token-Austausch muss von einem Backend übernommen werden.
  • Stelle sicher, dass die Redirect URI bei deiner GitHub OAuth-App eingetragen ist.
