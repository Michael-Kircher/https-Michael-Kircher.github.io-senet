Senet Web App

Diese statische Seite ist für GitHub Pages vorbereitet. Die echte Anwendung wird beim Deployment aus dem Vite-Build erzeugt.

Die Browser-Anwendung wird nach dem Upload ins GitHub-Repository und erfolgreichem Build auf GitHub Pages ausgeliefert.

Für lokale Vorschau und Produktion verwendet das Projekt Vite und GitHub Actions.
